# Latin Modern Roman

Unmodified font files of Latin Modern, the font of the LaTeX report, so the figures use it without a LaTeX installation:

| File | Font | Version |
|---|---|---|
| `lmroman10-regular.otf` | LMRoman10-Regular | 2.004 |
| `lmroman10-italic.otf` | LMRoman10-Italic | 2.004 |
| `lmroman10-bold.otf` | LMRoman10-Bold | 2.004 |

These are three files of the Latin Modern collection, copied unchanged and with their original names from the TeX distribution (`fonts/opentype/public/lm/`). The complete collection with its manifest and documentation is available from CTAN: https://ctan.org/pkg/lm.
